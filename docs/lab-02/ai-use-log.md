# Lab 2 AI Use — Full Prompt Log

The companion to [`ai-use.md`](./ai-use.md), which carries what §14 Part 4 asks for: the
models used, ten selected prompts, and the reflection. This file is everything else, and it
is here rather than there so the submitted document stays the length the labsheet means by
"concise" while nothing is thrown away.

Two sections. The first is every prompt I typed, the ten selected among them. The second is
the briefs the main agent wrote to its own sub-agents, which are not my prompts and are kept
apart from them for that reason.

The reason for keeping either is the same: a prompt cannot be reconstructed accurately weeks
after it was typed, and the ones that look minor are often the ones that stopped something
going wrong.
